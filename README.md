# Fireplace

I really just wanted to try and implement a function I saw online, and to warm up my skills in programming. I want to do more and be better OK? writing this in C. might also do it in Rust some time soon to try and learn more.

### Dependancy:

- C
- SDL2 (I know SDL3 is out allready)
- Nuklear

### To Run
1. Make sure you have SDL installed
2. run `make`
3. run `./bin/Fireplace`
